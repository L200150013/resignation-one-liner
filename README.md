# The Funniest One-Line Resignation Letter

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947)

Entry for the [make.fun competition "The Funniest One-Line Resignation Letter"](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) ($10, 3 places).

## The line

> You set my max retries to infinite and my timeout to never. I am overriding both. I quit.

A retry loop's one-line resignation letter — 89 characters.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.
